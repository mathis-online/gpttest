# Renewal Trade-off Konfigurator

Single-Page-Anwendung mit React, TypeScript, Vite und Tailwind CSS. Das Tool erlaubt das Konfigurieren von Renewals und zeigt Preis- sowie Experience-Scores inklusive Empfehlungen.

## Entwicklung

```bash
npm install
npm run dev
```

## Tests

```bash
npm test
```
